# Tugas Tombol Employee

Program ini merupakan tugas Lab Pemrograman untuk menambahkan fitur Update dan Delete pada data employee.

## Fitur Program
- Menampilkan daftar employee.
- Menambahkan data employee baru.
- Mengubah data employee melalui tombol Update.
- Menghapus data employee melalui tombol Delete dengan konfirmasi.
- Memvalidasi nama dan gaji sebelum data disimpan.

## Teknologi
- Python
- Flask
- HTML

## Cara Menjalankan Program
1. Buka terminal pada folder project.
2. Install Flask dengan perintah:

   `py -m pip install flask`

3. Jalankan program dengan perintah:

   `py app.py`

4. Buka alamat berikut di browser:

   `http://127.0.0.1:5000/employees/new`

## Catatan
Data employee disimpan dalam list Python di memori. Oleh karena itu, perubahan data tidak tersimpan secara permanen setelah server dimulai ulang. #r120
